# Cookie Sound Effects

Cookie ships with a synthesized set of cute cat vocalizations and effects
(generated by `scripts/make_sounds.swift`): a pitch-bent meow, a rumbling
purr, a happy "mrrp!", tiny mews, surprise squeaks, munches, toy blips,
landing thuds, and soft nap breathing. All are small mono WAV files in
this folder, loaded by `AudioManager` at runtime.

Real recordings can replace any of them — keep the file name, drop in
your own WAV/AIFF/MP3 (a `cookie-<name>` file at the bundle root also
wins over the Sounds folder copy).

| Effect      | File name           | Used for                                  |
| ----------- | ------------------- | ----------------------------------------- |
| Purr        | `cookie-purr`       | Petting strokes, head pets, happy cats    |
| Meow        | `cookie-meow`       | Meows, mild protests, spontaneous meows   |
| Happy       | `cookie-happy`      | The rising "mrrp!" on happy reactions     |
| Mew         | `cookie-mew`        | The shy reaction                          |
| Surprise    | `cookie-surprise`   | Nose taps, tail touches                   |
| Eat         | `cookie-eat`        | Entering the eating state                 |
| Toy         | `cookie-toy`        | Double-click play bursts                  |
| Drop        | `cookie-drop`       | Landing after being let go                |
| Chirp       | `cookie-chirp`      | Noticing the cursor nearby                |
| Sleep       | `cookie-sleep`      | Settling into a nap                       |
| Welcome     | `cookie-welcome`    | First-run greeting                        |

Playback is throttled per effect (purr at most once per second, the rest
once per 0.35 s), meows follow the Settings "Meow volume" slider, other
effects follow the master volume, and sound can be turned off entirely
in Settings → Sound.
