# Love Emote Artwork

## Overview
- **Identifier**: `love`
- **Animation Sequence**: Cookie tilts her head with deep affection, soft squished posture, sweet closed happy eyes, maximum blush, giving an affectionate little nuzzle.
- **Sound Effect**: `cookie-mew` (tender shy mew / purr)
- **Target Frame Rate**: 6 FPS
- **Playback**: One-shot (`loop: false`)

## Asset Drop-In
To supply final artwork:
- Option A: Place `love.png` grid sheet in this directory along with grid dimensions in `emote.json`.
- Option B: Place `frame0.png`, `frame1.png`, etc. (180×180 pt transparent PNGs).

When no files are present, Cookie automatically executes the procedural affection sequence derived from the reference artwork.
